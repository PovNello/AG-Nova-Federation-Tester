Graph API Pull

Pull-based sync: your application authenticates to Microsoft Graph as itself (client credentials) and reads users from Entra ID. Choose which users to import with an inclusion filter.

⚙️ Calls run server-side via /api/graph-pull. The backend only talks to graph.microsoft.com/…/users. It returns the exact request it sent plus the Graph response. Required Application permission: User.Read.All (with admin consent).
1
Configuration

App registration in Entra ID → Overview (tenant + client id) and Certificates & secrets (client secret). The secret is never saved in the browser.

2
Access Token

Client credentials grant against the Entra token endpoint, with scope https://graph.microsoft.com/.default (= all application permissions granted to the app).

3
Inclusion Filter

Only users matching all conditions are pulled (conditions are joined with and). No condition = all users. Pick an Entra property, an operator and a value. Filters on ne, endsWith and extension attributes use Graph advanced queries — the page then adds ConsistencyLevel: eventual and $count=true for you.

Filtered properties are added automatically. Empty = Graph defaults.
If set, replaces the conditions above.
