Authorization Code + Client Secret

Confidential client flow — the token exchange uses a client secret. The secret is sent to our backend proxy per-request and never stored.

⚙️ The token exchange (Step 4) is proxied through /api/token-exchange so the client secret is kept out of browser headers/logs. The exact request the backend makes is returned and shown below.
